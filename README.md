# campus-bus-navi（バスNAVI）

福山大学のスクールバスについて、次の発車時刻、当日の時刻表、乗り場を見やすく案内する Web アプリ（PWA）です。学生・教職員が時刻表を探す手間や乗り場で迷う時間を減らすことを目指しています。

このアプリは **非公式の個人運営** です。福山大学を代表するもの、大学による承認・保証を示すものではありません。

[アプリを開く](https://campus-bus-navi.pages.dev/)

> 現在はベータ版として運用しています。試験、移動、重要な予定に関わる場合は、必ず大学公式の時刻表・お知らせも確認してください。

## できること

- 現在時刻（日本時間）に基づく次のバス、残り本数、直近の発車時刻の表示
- 松永発・大学発の切替と、当日の全時刻表の確認
- 日付ごとのルールに基づく授業日、休業日、長期休暇、イベント日などのダイヤ切替
- 全便運休日や、時刻を安全に確定できない特別ダイヤの案内
- OpenStreetMap 上の乗り場表示と、端末の地図アプリへの徒歩経路引継ぎ
- お知らせ、テーマ、文字サイズ、初期表示路線の設定
- 一度取得した時刻表・お知らせ・地図タイルのオフライン表示

## 使い方

- 左上のメニューから、お知らせ、設定、ヘルプ、アプリの初期化を開けます。
- 上部の切替で「大学発」と「松永発」を選べます。
- 右上の更新ボタンは、時刻データをサーバーから取り直します。
- iPhone / iPad は Safari、Android は Chrome などのブラウザからホーム画面へ追加できます。

特別ダイヤの日は、誤った時刻を推測して表示しないため、発車時刻の代わりに大学公式サイトの確認先を案内します。全便運休日には、翌日の始発を案内します。

## 時刻表・通信について

利用者向けアプリは API やデータベースを持たない静的な構成です。時刻表、カレンダー、お知らせはアプリ起動時に最新取得を優先し、通信できないときは端末に保存された前回取得分を表示します。そのため、通信状況や開いたままの画面では、更新直後の情報がただちに表示されない場合があります。

時刻表データは日付ごとのルールで選択されます。端末で祝日を自動判定しているわけではありません。
